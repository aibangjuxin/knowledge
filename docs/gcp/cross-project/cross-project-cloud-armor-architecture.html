Cross-Project Cloud Armor — 3 valid paths + 1 rejected

  • Tenant Project 创建 security-policy + 绑定到自己的 BS
  • Master Project 不创建任何 Cloud Armor
  • 完整命令见 skills/architectrue/references/cross-project-psc-environment-aibang.md Step 7
  • europe-west2 / dev-lon-cluster 已生产验证

多 Tenant IaC 分发 — 关键约束

  • 每个 tenant 的 runner SA 必须在 tenant project 有 securityAdmin + networkAdmin
  • policy 必须重建,不能 terraform import 跨 project
  • WAF 规则更新 = 改 Git → CI 自动推到 N 个 tenant
  • 50+ tenants 时考虑 Terraform Cloud / Atlantis 集中化

Hierarchical Firewall vs Cloud Armor

  • Hierarchical FW 是 VPC firewall,不是 Cloud Armor
  • 能力:deny IP/port ✓ · SQli/XSS ✗ · rate-limit ✗
  • 适用场景:全 Org 范围的 IP 黑名单(僵尸网络 / 已知攻击者)
  • 不要混用:不能把"做 WAF"的活让 Hierarchical FW 替代 Cloud Armor
