Why this design (vs LEGACY)

  • • 干掉 MIG: 省 VM 运维成本 + 省 Regional ILB 费用(~$18/月)
  • • 少一跳: GLB → PSC → K8s Pod(老: GLB → PSC → ILB → MIG → K8s)
  • • 独立 Project: Master 单独计费/配额/审计,不污染 Tenant
  • • Org Policy 触发面缩小: Tenant 内部违规不影响 Master
  • • 向后兼容: 老 LEGACY cinternal 链路不动,DNS weight 切流量,无 downtime
  • • K8s 原生扩缩容: HPA 直接扩 Pod,不用管 MIG instance template
