SMB 关键事实

  • • TCP 445 · 文件系统 mount
  • • 需 Secret(user/pass)
  • • 签名 + 加密(SMB 3.0+)
  • • 跨 platform 审计断链
  • • 配套: nas/ADR-009

NFS 关键事实

  • • TCP 2049 · 文件系统 mount
  • • 无 Secret(IP + UID)
  • • NFSv3 明文!
  • • Linux 内核原生支持
  • • 配套: nfs/ 部署指南

Bucket 关键事实

  • • HTTPS · API 调用(无 CSI)
  • • KSA → WIF → 短期 token
  • • 跨 project IAM policy
  • • 必触发 R1(档 1)
  • • 配套: buckets/ADR-011
