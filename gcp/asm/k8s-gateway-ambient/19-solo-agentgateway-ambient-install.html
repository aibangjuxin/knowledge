Solo Istio 1.30.3 Ambient + agentGateway + KongDP · GKE

整体流量架构 · Kong 前置网关模式 · 5 跳南北向 + ztunnel L4 HBONE + agentGateway waypoint L7 CEL

关键决策:Kong 必须放 mesh 外

  • · 角色冲突:Kong 自己是 L7 网关,mesh 内再加 waypoint L7 是冗余
  • · License 边界:Kong plugin chain 不应受 istio AuthPolicy 干扰
  • · 职责清晰:Kong = 对外鉴权(OAuth/API Key),mesh = 对内零信任(mTLS + SPIFFE)
  • · Kong 不带 ambient label,不 enroll waypoint
  • · Kong → Runtime 段鉴权:Kong 自身 plugin;Runtime ↔ Runtime:ztunnel mTLS

3 个 GatewayClass 分工

  • · enterprise-agentgateway = 南北向 ingress Gateway(放 agentgateway-system ns)
  • · enterprise-agentgateway-waypoint = ambient L7 waypoint(CEL 策略,Alpha 状态)
  • · istio-waypoint = 社区 waypoint(Envoy,GA,可并存)
  • · B 和 C 不能同 ns 共存(同监听 :15008/HBONE 冲突)
  • · A 至少 1 个;B/C 同 ns 二选一

关键 Host 头 / mTLS 链

  • · Kong route 匹配强依赖 Host → Istio Gateway 不要 URLRewrite hostname
  • · ztunnel 不解析 Host,只走 Service VIP → backendRefs 必须指向 Kong Service
  • · Kong → Runtime 默认明文 HTTP(必须 Kong 配 TLS upstream 或 Kong 入 mesh)
  • · PILOT_HBONE_INITIAL_STREAM_WINDOW_SIZE 调大,防大文件上传截断
  • · DestinationRule ISTIO_MUTUAL 在 ambient 下基本不生效
