Global external ALB (NEW · 12 个新资源)

  • • FR: caep-mig-public-fr (EXTERNAL_MANAGED --global)
  • • Cert: caep-mig-public-cert (复用 A 工程 cert 副本)
  • • URL Map: caep-mig-public-um (3 path rule + default)
  • • Target HTTPS Proxy: caep-mig-public-proxy
  • • Default BS: caep-mig-public-default-bs (EXTERNAL_MANAGED + dummy MIG)
  • • apiname1/2 BS: caep-mig-apiname1-bs + caep-mig-apiname2-bs (EXTERNAL_MANAGED,backends = 旧 BS 同 MIG)
  • • apiname3 BS: caep-mig-apiname3-bs (EXTERNAL_MANAGED + PSC NEG)
  • • apiname3 PSC NEG: caep-mig-apiname3-neg (regional,→ B SA-3)
  • • apiname3 Cloud Armor: caep-mig-apiname3-armor (独立)
  • • IP: caep-mig-public-glb-ip (=NEW_IP,阶段 7 DNS 切换目标)

Master B (apiname3 专属 · 8 个新资源)

  • • Service Attachment: caep-master-sa-3 (ACCEPT_AUTOMATIC)
  • • Producer NAT subnet: caep-master-nat-subnet (purpose=PRIVATE_SERVICE_CONNECT)
  • • L7 Internal Application LB: caep-apiname3-ilb-fr (INTERNAL_MANAGED :443)
  • • ILB BS: caep-apiname3-bs
  • • MIG (nginx): caep-apiname3-mig (instance template 拉 nginx.conf)
  • • URL Map + Target HTTPS Proxy
  • • Cert: *.caep.uk (B 侧副本,SAN 含 www.caep.uk)
  • • K8s Gateway + HTTPRoute (B 工程已有,本方案复用)
  • • 详见: public-fqdn-explorer.md §3.5 + baseing-path-cross-project.md §4

关键不变量(★ 业务零感知的物理基础)

  • • backend pool:apiname1/2 的 MIG / VM / nginx / 应用 0 改动
  • • Cloud Armor policy:apiname1/2 的 rule / rate limit / WAF 0 改动,只是 BS 引用关系变了
  • • 请求链路变化只在 LB 控制面(FR / Proxy / URL Map / BS)
  • • apiname3:BS 在 A 工程(EXTERNAL_MANAGED),backend 是 PSC NEG(→ B SA-3)
  • • 回滚:任何阶段 DNS 还指 OLD_IP,100% 旧 LB 状态可达
  • • 总时长:1-7 天(主要是 Phase 6 灰度观察期)
