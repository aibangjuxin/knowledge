4 维度约束(架构师核心)

  • · 公网: EXTERNAL 系(排除 3 种 INTERNAL)
  • · PSC NEG: MANAGED 系(排除 2 种经典 EXTERNAL)
  • · L7: HTTP/HTTPS 协议(排除 3 种 L4)
  • · Global: 跨 region(排除 1 种 Regional)
  • · 4 维度联合 → 唯一 = GLOBAL_EXTERNAL_MANAGED_HTTP_HTTPS

能力清单

  • · L7 URL Map (path / host / header 路由)
  • · Host rewrite (routeAction.urlRewrite.hostRewrite)
  • · Path rewrite (pathPrefixRewrite / regexRewrite)
  • · Cloud Armor (WAF / DDoS / Rate limit)
  • · HTTP/2 + HTTP/3 (QUIC)
  • · 任播静态 IP (Anycast)

常见误解

  • · ❌ "EXTERNAL 都支持 PSC NEG" — 仅 MANAGED
  • · ❌ "Regional LB 也能跨 project" — 但单 region
  • · ❌ "INTERNAL_MANAGED 也能跨 project" — 不支持 PSC NEG
  • · ❌ "TCP/SSL Proxy 也能 L7 路由" — 仅 L4

Org Policy 阻塞项

  • · 默认 allowedLoadBalancingScheme = [INTERNAL]
  • · 需要申请扩展 EXTERNAL / GLOBAL_EXTERNAL_MANAGED
  • · Security 审批: 1-3 工作日
  • · 推荐显式列出 GLOBAL_EXTERNAL_MANAGED_HTTP_HTTPS
  • · 配 Cloud Armor 才合规
