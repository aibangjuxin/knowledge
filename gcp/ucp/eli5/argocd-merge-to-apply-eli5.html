我改了 Git，怎么集群才知道？

一次 merge 到真正建集群 · 讲给五岁小孩

先回答

改分支，不会部署。只有合进 main 才会。

main 是“正式生效的那一摞纸”，别的都是草稿。

三步，像三个人接力

  1. 听到消息 —— Argo CD 被叫醒：“有新提交了，去看看。”
  2. 去取货 —— 它去 Git 拿 main 那一版，算出“应该长什么样”。
  3. 动手搬 —— 对比现在真实的和应该的，不一样就改。

第 1 步可能等几秒，也可能等 2 分钟。慢一点没关系，最后都会对上。

改完就等多久？

然后呢？

搬完之后，XR 出现在集群里。Crossplane 一看见就开工，真的去 GCP 建集群，然后把结果写回同一张单子上。

Argo CD 再看见单子变了，把状态标成 Synced / Healthy。

危险的按钮

prune：“把 Git 里删掉的东西，也从云上删掉”。
开着它，删一行 YAML 可能真的把云集群删掉。PoC 阶段建议关掉。
