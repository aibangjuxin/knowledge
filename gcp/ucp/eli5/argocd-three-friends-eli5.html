三个名字很像的朋友，谁是谁？

Argo CD 的零件们 · 讲给五岁小孩

三个零件

会干活的人

applicationset controller

扫 Git 的目录，批量造出一张张“任务单”。

会干活的人

application controller

拿任务单去对比真实情况，该改的改。它才真的动手。

会干活的人

repo server

专门去 Git 取货、展开、缓存。

两个不是人的东西

一张单子

Application

写着“从哪个仓库哪个目录来、送到哪个集群、什么时候同步”。它自己什么都不做。

一张规则

ApplicationSet

“每个文件夹造一张单子”的规则。

谁不干活会怎样？

applicationset controller 停 → 没有单子。
application controller 停 → 有单子，但永远不动手。
repo server 停 → 两个都取不到货。

文件夹就是规矩

teams/team-a/project-a/ → 单子 team-a-project-a
→ 放进 project-a 这个房间

文件夹名 = 房间名 = 允许名单里写的名字。三处一样才不吵架。
